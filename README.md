# 👩🏾‍💻 Evelyn Oliveira

**`Software Engineer | Java Back-End Developer | AWS & Cloud Computing | Building Scalable Solutions`**

### 🚀 Architecting scalable backends to power intelligent, high-impact solutions.

Sou Engenheira de Software formada pela UniCesumar e vejo o desenvolvimento Back-End e a Computação em Nuvem não apenas como linhas de código, mas como a infraestrutura invisível que sustenta grandes transformações digitais e sociais. Meu foco diário é projetar soluções robustas com **Java** e **Spring Boot**, arquitetando deploys inteligentes, seguros e escaláveis no ecossistema **AWS**.

Acredito que o verdadeiro papel da engenharia começa muito antes de abrir a IDE. Essa perspectiva me levou a co-autorar o **Orion Map** durante o Hackathon UniCesumar: uma solução mobile focada em acessibilidade urbana onde desenhei toda a arquitetura de dados e requisitos em nuvem, integrando a inteligência da **Gemini API** para processar visão computacional em tempo real. Para mim, software de verdade é aquele que entrega eficiência e devolve autonomia às pessoas.

Combinando uma sólida base conceitual de _System Design_ com a prática intensa de laboratórios em Cloud (GCP/AWS) e maratonas de programação, desenvolvi uma forte mentalidade analítica, senso de dono e resiliência para atuar sob pressão.

Atualmente, estou em busca do meu próximo grande desafio como **Trainee ou Desenvolvedora Júnior**. Estou pronta para aprender rápido, contribuir em equipes de alta performance e transformar problemas complexos em arquiteturas elegantes.

Se você busca uma profissional obcecada por eficiência, com paixão por IA e pronta para colocar a mão na massa, vamos conversar!
